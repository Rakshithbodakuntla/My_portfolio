# Rakshith Bodakuntla — AI/ML Portfolio

A responsive React portfolio rebuilt from Rakshith's current resume.

## Included

- Resume-aligned hero, biography, skills, work history, credentials, and contact information
- Production impact metrics from Databricks and Amazon experience
- Enterprise case studies plus selected GitHub projects
- Responsive navigation and mobile layout
- Interactive pointer glow and animated profile card
- Downloadable resume in `public/Rakshith_Bodakuntla_Resume.pdf`
- Contact form that opens the visitor's email application

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Edit content arrays near the top of `src/App.jsx`.
- Change colors and layout variables in `src/styles.css`.
- Replace `public/Rakshith_Bodakuntla_Resume.pdf` when the resume changes.
- Update LinkedIn, GitHub, email, phone, and location in `src/App.jsx` as needed.

## Deployment

The project works with Vercel, Netlify, GitHub Pages, or any static Vite hosting workflow.
